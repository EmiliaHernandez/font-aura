**Discover your unique font aura by typing in your name and see which Google Font matches your energy.**

This is a simple project reminiscent of fun internet websites where you can just spend your time typing the names of different people you know and laugh at the results. My goal with the project was to brush up on API integration, as well as deployment with Vercel.

Tech used:
- Google Fonts API
- Next.JS
- React
- Vercel
